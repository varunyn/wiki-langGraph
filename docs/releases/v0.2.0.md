# Release v0.2.0

Release date: 2026-05-27

## Highlights

- Upgraded the LLM/wiki stack to newer Deep Agents, LangChain OpenAI, LangGraph, QMD, pytest, and ruff-compatible tooling.
- Added interactive wiki exploration with `wiki-langgraph query`.
- Added research-mode synthesis with `wiki-langgraph research`.
- Added save-to-vault compounding: `query --save` writes raw notes under `Queries/`, and `research --save` writes raw notes under `Research/` so future runs can compile and retrieve them.
- Added an LLM compile review queue for risky or all generated candidates.
- Tightened link provenance so authored backlinks stay separate from generated semantic suggestions.

## Added

- `wiki-langgraph query "..."` retrieves relevant compiled wiki notes, asks the configured chat model, and prints an answer with source note scores.
- `wiki-langgraph query "..." --save` saves the answer as a raw markdown note under `Queries/`.
- `wiki-langgraph research "..."` retrieves a broader context set and asks the model for a structured research brief.
- `wiki-langgraph research "..." --save` saves the brief as a raw markdown note under `Research/`.
- `wiki-langgraph review list/show/approve/reject` manages LLM compile candidates under `data/.wiki-langgraph/candidates/`.
- `WIKI_LLM_COMPILE_REVIEW=off|risky|all` controls whether generated LLM compile output is written immediately or queued for review.
- LangGraph node timeout settings:
  - `WIKI_GRAPH_INGEST_TIMEOUT_SEC`
  - `WIKI_GRAPH_COMPILE_TIMEOUT_SEC`
  - `WIKI_GRAPH_INDEX_TIMEOUT_SEC`
  - `WIKI_GRAPH_LINT_TIMEOUT_SEC`
- QMD tuning settings:
  - `WIKI_QMD_CANDIDATE_LIMIT`
  - `WIKI_QMD_NO_RERANK`
  - `WIKI_QMD_CHUNK_STRATEGY`
  - `WIKI_QMD_EMBED_MAX_DOCS_PER_BATCH`
  - `WIKI_QMD_EMBED_MAX_BATCH_MB`
- Deep Agents filesystem safeguards that deny access to `.env`, `.git`, `.codegraph`, and internal agent artifact paths.
- Deep Agents memory loading from `AGENTS.md` when present.
- More coverage for query, research, review queue, QMD command construction, LangGraph timeout/error behavior, and link provenance.

## Changed

- `deepagents` upgraded from `0.4.12` to `0.6.4`.
- `langchain-openai` upgraded from `1.1.12` to `1.2.2`.
- `langgraph` requirement updated to `>=1.1.6`.
- Added `ruff` to the dev dependency group.
- LangGraph execution now uses async node wrappers with configured node timeouts and error handlers.
- LLM author output extraction now handles LangChain/provider message shapes beyond plain string content.
- QMD semantic search now passes candidate limits, optional no-rerank/no-gpu flags, and chunk strategy.
- QMD refresh now passes chunk strategy and optional embed batching controls.
- Logging with no `WIKI_LOG_FILE` now uses a `NullHandler` so package logs do not leak to `lastResort`.
- `wiki-langgraph run -v` no longer prints failed step logs twice.
- If the generated wiki directory lives inside the raw vault, ingest and lint source enumeration now exclude that generated output directory.
- Incremental LLM compile preserves existing authored wiki notes for unchanged raw files instead of overwriting them with raw source text.
- Package runtime version now reports `0.2.0`.

## Fixed

- Backlinks are now computed only from authored note content; preserved generated `See also` blocks no longer create false authored backlinks.
- `Index.md` drift lint ignores the generated index self-link.
- Index entry building skips generated index notes.
- Orphan-note lint can use compiled wiki text when available, so LLM/semantic-injected outgoing links are considered.
- Risky LLM review candidates do not update manifest hashes until approved.
- Queued new LLM review candidates are not written into the compiled wiki before approval.

## Documentation

- README now documents command reference, query/save compounding, research briefs, review queue, link provenance, QMD settings, Deep Agents behavior, and layout.
- Architecture docs now cover LangGraph timeouts, review queue flow, query/research call sites, and CLI behavior.

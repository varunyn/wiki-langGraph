# Release v0.3.0

Release date: 2026-07-06

## Highlights

- Added an Open Knowledge Format (OKF) output profile for compiled markdown.
- Standard Markdown links are now the default for compiled note content, generated graph sections, and `index.md`.
- Compiled OKF concept notes receive the required `type: Note` frontmatter field.
- Preserved the legacy Obsidian wikilink output profile through `WIKI_OUTPUT_PROFILE=obsidian`.

## Added

- `WIKI_OUTPUT_PROFILE=okf|obsidian` configuration, defaulting to `okf`.
- Lowercase `index.md` generation with migration from legacy generated `Index.md` files.
- OKF linting for missing concept `type` frontmatter and Markdown-link-aware orphan/index checks.
- Regression coverage for OKF links, frontmatter, index migration, linting, and graph-count preservation.

## Changed

- Authored source `[[wikilinks]]` remain the provenance source for backlinks, while compiled OKF output uses ordinary relative Markdown links.
- Generated semantic sections and index navigation use standard Markdown links in the default profile.
- Package runtime version now reports `0.3.0`.

## Documentation

- README and architecture documentation now describe the OKF profile, lowercase index convention, and legacy compatibility mode.

## Verification

- Python source compilation and `git diff --check` pass.
- Full pytest verification should be run with `uv run pytest` before tagging; the current environment does not have `uv` installed.

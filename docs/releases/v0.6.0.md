# Release v0.6.0

Release date: 2026-09-04

## Highlights

- Added optional Langfuse v4 tracing across pipeline steps, retrieval, and current LLM call paths.
- Added versioned research, bounded-agent, and knowledge-gap evaluation datasets with executable
  CLI experiments and deterministic application-specific scores.
- Added isolated fixtures for bounded agent behavior and read-only knowledge-gap review so those
  experiments do not depend on the developer's active vault.
- Added exact hosted dataset-version selection, explicit Langfuse flushing, release/environment
  metadata, and evaluator diagnostics for missing themes, sources, and citations.
- Tightened research and knowledge-gap prompts based on observed experiment failures, including
  source wikilink requirements and the distinction between partial review scope and missing
  raw/wiki counterparts.
- Added curated raw and compiled architecture notes covering LangGraph execution, state,
  reliability, bounded control, and the two DeepAgent review roles.

## Verification

- Full pytest suite passed: 196 tests.
- Ruff passed for the changed Python source and tests.
- Strict raw/wiki lint passed with zero issues.
- OCI OpenAI-compatible chat, structured output, and tool calling were exercised through the
  knowledge-gap experiments, with traces and evaluator observations recorded in Langfuse.

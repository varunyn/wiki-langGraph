# Release v0.5.0

Release date: 2026-08-31

## Highlights

- Added `wiki-langgraph review gaps [scope] [--limit N]` for bounded editorial analysis of the raw
  and compiled wiki corpus.
- Reused the existing DeepAgent factory with an exact file-level read allowlist and denied all
  filesystem writes.
- Added deterministic scope normalization, raw-to-wiki mapping, authored-link analysis, lint
  evidence, candidate selection, and partial-coverage reporting.
- Added validated structured findings for missing concepts, missing overviews, weak connections,
  possible duplicates, possible conflicts, and source-coverage gaps.
- Required every finding to cite evidence from successful DeepAgent filesystem tool calls.
- Kept the feature advisory: it does not modify notes, the manifest, QMD state, or the compile
  candidate queue.
